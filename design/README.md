# MarketPeek 디자인 시안

위젯 · 앱 화면 · 앱 아이콘 · 잠금화면 디자인 시안 모음입니다. (디자인: 이효원)
디자인 캔버스의 보드 249개를 2배 해상도 PNG로 내보냈습니다.

- 시세 · 환율 · 뉴스 문구는 모두 디자인용 예시 데이터이며 실제 시세가 아닙니다. 값을 모르는 종목은 0으로 비워 두었습니다.
- 종목 로고 자리는 이니셜입니다.
- 상승 · 하락 색은 한국식 기본값(상승 빨강, 하락 파랑)으로 내보냈습니다.
- 잠금화면 배너(라이브 액티비티형)는 기획서상 이번 버전 제외 기능이라 참고용입니다.
